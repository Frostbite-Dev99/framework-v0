# framework-v0

Reusable Unity 6 game framework (`Assets/_Framework`) + a small reference game that proves it (`Assets/_Game`).

**New here?** Read `Docs/01` → `02` → `03`, then run `git config core.hooksPath .githooks`.

## What each file / folder is for
| Path | What it's for |
| --- | --- |
| `Assets/_Framework/` | Reusable framework modules (`FW_<Layer>_<Module>/`), each with its own README |
| `Assets/_Game/` | The reference game built on the framework |
| `Assets/_Sandbox/` | Personal experiments (`_Sandbox/<YourName>/`), never referenced by real code |
| `Assets/ThirdParty/` | Asset Store / external imports. Don't edit |
| `Docs/01-csharp-best-practices.md` | How we write C# in Unity |
| `Docs/02-github-workflow.md` | Issues → branch → commit → PR → review → merge, rebase, cheat sheet |
| `Docs/03-ci-and-releases.md` | What CI checks, how releases/changelog work, one-time admin setup |
| `CHANGELOG.md` · `version.txt` | Generated by release-please. Don't edit |
| `release-please-config.json` · `.release-please-manifest.json` | release-please settings / current version |
| `.github/workflows/` | CI (`ci.yml`), PR title + issue checks (`pr-checks.yml`), issue-owner bot, release + auto-merge |
| `.github/scripts/` | Check scripts CI runs. You can run them locally too |
| `.github/ISSUE_TEMPLATE/` | Feature / Bug / Task issue forms |
| `.github/pull_request_template.md` | PR checklist, pre-filled when you open a PR |
| `.github/CODEOWNERS` | Makes a team lead's review required |
| `.githooks/commit-msg` | Adds `(#issue)` to your commit messages from the branch name |
| `Scripts/SetupGitHubRepo.sh` | One-time admin script: teams, labels, branch protection |
| `.editorconfig` | IDE formatting and naming rules |
| `.gitignore` · `.gitattributes` | What Git ignores / which files go through Git LFS |
| `Packages/` · `ProjectSettings/` | Unity project config (commit these) |
